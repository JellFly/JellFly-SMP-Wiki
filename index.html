Java Edition Disponible

Édition Java

Version du serveur : 1.21.11 · Clients compatibles : 1.17 à 26.3

Adresse du serveur smp.jellfly.win

  1. Lancez Minecraft et ouvrez le menu Multijoueur.
  2. Ajoutez un serveur avec le nom « JellFly SMP » et l’adresse indiquée ci-dessus.
  3. À la première connexion, choisissez un mot de passe d’au moins 5 chiffres. Vous en aurez besoin lors de vos prochaines connexions.
Vous avez acheté Minecraft (compte Premium) ?

Utilisez la commande /premium pour vous reconnecter ensuite sans saisir votre mot de passe à chaque fois.

PC Windows

Dans Minecraft, ouvrez Jouer → Serveurs → Ajouter un serveur, puis saisissez l’adresse et le port affichés ci-dessus.

Connexion sur console (Switch, PlayStation et Xbox)

Les consoles ne permettent pas d’ajouter directement une IP de serveur dans Minecraft. BedrockConnect utilise un DNS tiers pour ouvrir un menu de serveurs personnalisés depuis la liste des serveurs en vedette.

Nintendo Switch
  1. Depuis l’écran d’accueil, ouvrez Paramètres de la console → Internet → Paramètres Internet.
  2. Sélectionnez votre réseau, puis Modifier les paramètres → Paramètres DNS → Manuel.
  3. DNS primaire : 104.238.130.180. DNS secondaire : 8.8.8.8. Enregistrez.
Xbox One / Series X|S
  1. Appuyez sur la touche Xbox, puis ouvrez Profil et système → Paramètres → Général → Paramètres réseau → Paramètres avancés → Paramètres DNS → Manuel.
  2. DNS primaire : 104.238.130.180. DNS secondaire : 8.8.8.8. Enregistrez.
PlayStation 4 / 5
  1. Ouvrez Paramètres → Réseau, puis la configuration de votre connexion Internet.
  2. PS5 : sélectionnez le réseau, puis Paramètres avancés → Paramètres DNS → Manuel. PS4 : choisissez Personnalisé, gardez l’IP sur Automatique et le nom d’hôte DHCP sur Ne pas spécifier, puis réglez le DNS sur Manuel.
  3. DNS primaire : 45.55.68.52. DNS secondaire : 8.8.8.8. Sur PS4, laissez MTU sur Automatique et le proxy désactivé. Enregistrez et testez la connexion.
Ouvrir le menu de redirection
  1. Relancez Minecraft, puis ouvrez Jouer → Serveurs.
  2. Rejoignez un serveur en vedette compatible avec la redirection : Mineville, Lifeboat, Enchanted, Galaxite ou The Hive. Cela ouvre le menu BedrockConnect.
  3. Dans ce menu, ajoutez smp.jellfly.win avec le port 7826, puis connectez-vous.

Cette méthode DNS est un service tiers, pas une fonction officielle de Minecraft. Si elle perturbe la connexion, remettez les DNS en Automatique. Les services publics peuvent changer d’adresse ou être indisponibles ; consultez le guide BedrockConnect et son état des services. La méthode publique « Ajouter un ami » est actuellement désactivée par le projet.

Java Edition Disponible

Rejoindre le chat vocal

Le serveur utilise Simple Voice Chat. Installez le mod côté client pour discuter avec les joueurs à proximité.

Plateforme Modrinth ↗ Plateforme CurseForge ↗

Installation

  1. Téléchargez Simple Voice Chat pour votre version de Minecraft et votre chargeur de mods : Fabric, Forge ou NeoForge.
  2. Placez le fichier dans le dossier mods, puis lancez le bon profil Minecraft.
  3. Connectez-vous à JellFly SMP en Java Edition.

Configuration

  1. En jeu, appuyez sur V pour ouvrir les réglages du mod.
  2. Sélectionnez votre microphone et votre sortie audio.
  3. Utilisez la touche configurée pour parler (par défaut, Verr. maj. en mode push-to-talk).
  4. Pour ne plus être en push-to-talk, ouvrez les réglages du mod, choisissez Activation vocale, puis ajustez le curseur de sensibilité jusqu’à ce que votre voix soit détectée sans maintenir de touche.

Si l’icône du mod indique qu’il n’est pas connecté, vérifiez que le mod correspond à votre version de Minecraft, puis reconnectez-vous au serveur. Le mod n’est pas nécessaire pour Minecraft Bedrock.

Guide de démarrage

Votre premier jour sur JellFly

Suivez ces étapes et commandes pour prendre vos marques sur le serveur.

  1. 01 /rules

    Lisez les règles pour connaître le fonctionnement du serveur.

  2. 02 /rtp

    Partez explorer la carte et choisissez où commencer votre aventure.

  3. 03 /sethome <nom>

    Enregistrez un point de retour à l’endroit de votre base.

  4. 04 /jobstats

    Consultez vos métiers et découvrez comment progresser.

  5. 05 /shop

    Vendez vos surplus et accédez aux boutiques du serveur.

  6. 06 /spawn

    Retournez au point de départ lorsque vous en avez besoin.
