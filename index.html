Rejoignez le serveur

Le serveur est accessible depuis Minecraft Java ou Bedrock. Suivez les étapes correspondant à votre édition.

Java Edition Disponible

Connectez-vous en quelques étapes

Adresse du serveur smp.jellfly.win

  1. Lancez Minecraft et ouvrez le menu Multijoueur.
  2. Ajoutez un serveur avec le nom « JellFly SMP » et l’adresse indiquée ci-dessus.
  3. Lors de votre première connexion, enregistrez un mot de passe de 6 chiffres avec cette commande : /register {mot de passe} {mot de passe}
  4. Retenez ce mot de passe : il vous sera demandé lors de vos prochaines connexions.
Bedrock Disponible

Édition Bedrock

Ajoutez JellFly SMP dans la liste des serveurs Bedrock avec les informations suivantes :

Adresse du serveur smp.jellfly.win
Port 7826

PC Windows

  1. Lancez Minecraft pour Windows (Bedrock) et ouvrez Jouer.
  2. Ouvrez l’onglet Serveurs, puis choisissez Ajouter un serveur.
  3. Saisissez « JellFly SMP », l’adresse smp.jellfly.win et le port 7826, puis enregistrez.
  4. Sélectionnez le serveur dans votre liste pour vous connecter.

Nintendo Switch, PlayStation et Xbox

Les consoles ne permettent pas d’ajouter directement une IP de serveur dans Minecraft. BedrockConnect utilise un DNS tiers pour ouvrir un menu de serveurs personnalisés depuis la liste des serveurs en vedette.

Nintendo Switch
  1. Depuis l’écran d’accueil, ouvrez Paramètres de la console → Internet → Paramètres Internet.
  2. Sélectionnez votre réseau, puis Modifier les paramètres → Paramètres DNS → Manuel.
  3. DNS primaire : 104.238.130.180. DNS secondaire : 8.8.8.8. Enregistrez.
Xbox One / Series X|S
  1. Appuyez sur la touche Xbox, puis ouvrez Profil et système → Paramètres → Général → Paramètres réseau → Paramètres avancés → Paramètres DNS → Manuel.
  2. DNS primaire : 104.238.130.180. DNS secondaire : 8.8.8.8. Enregistrez.
PlayStation 4 / 5
  1. Ouvrez Paramètres → Réseau, puis la configuration de votre connexion Internet.
  2. PS5 : sélectionnez le réseau, puis Paramètres avancés → Paramètres DNS → Manuel. PS4 : choisissez Personnalisé, gardez l’IP sur Automatique et le nom d’hôte DHCP sur Ne pas spécifier, puis réglez le DNS sur Manuel.
  3. DNS primaire : 45.55.68.52. DNS secondaire : 8.8.8.8. Sur PS4, laissez MTU sur Automatique et le proxy désactivé. Enregistrez et testez la connexion.
Ouvrir le menu de redirection
  1. Relancez Minecraft, puis ouvrez Jouer → Serveurs.
  2. Rejoignez un serveur en vedette compatible avec la redirection : Mineville, Lifeboat, Enchanted, Galaxite ou The Hive. Cela ouvre le menu BedrockConnect.
  3. Dans ce menu, ajoutez smp.jellfly.win avec le port 7826, puis connectez-vous.

Cette méthode DNS est un service tiers, pas une fonction officielle de Minecraft. Si elle perturbe la connexion, remettez les DNS en Automatique. Les services publics peuvent changer d’adresse ou être indisponibles ; consultez le guide BedrockConnect et son état des services. La méthode publique « Ajouter un ami » est actuellement désactivée par le projet.
